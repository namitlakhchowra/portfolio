Simplicity Bias Experimentation

Can simplicity override predictive strength?

  • Investigated simplicity bias in neural networks: whether models prefer simpler features even when more complex features are more predictive.
  • Generated a synthetic binary classification dataset with a threshold-based simple feature fixed at 75% predictive strength and a nonlinear sine-based complex feature whose strength rises from 75% to 100%.
  • Measured feature reliance on a conflict set where the two features disagree, estimating the transition point and visualizing how predictive strength shapes feature preference.
